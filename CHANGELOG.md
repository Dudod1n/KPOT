# История изменений

## 0.5.4 — 2026-10-17

### Добавлено

- Команда «Проверить обновление» в справке: результат ручной проверки и предложение установить новую версию или вернуться к ней позже.

### Исправлено

- Увеличена высота окна по умолчанию: строка подключения через jump-хосты в форме туннеля видна без прокрутки.
- Сохранение включённого автозапуска обновляет путь после переноса программы или перехода с прежней копии.
- Совпадающая запись автозапуска не перезаписывается; Windows-регистрация проверяется после изменения.
- Автозапуск Windows распознаёт официальные имена отдельных файлов релиза `krot-windows-x64.exe` и `krot-cli-windows-x64.exe`.

### Известные ограничения

- Windows-сборки пока не подписаны цифровой подписью издателя. Kaspersky может блокировать приложение при включении автозапуска; это ограничение не устранено в 0.5.4.

## 0.5.3 — 2026-10-16

### Добавлено

- Оконный интерфейс в терминальном стиле с анимированными кротами.
- SSH-туннели L/R/D, цепочки jump-хостов, SSH-agent, пароль и зашифрованные ключи.
- Проверка отпечатков SSH-узлов, журнал и восстановление соединений.
- Работа в фоне, системный трей, иконки приложения и CLI `krot-cli`.
- Закрытие окна в фон с уведомлением и флажком «Больше не показывать».
- Выбор при повторном запуске: отменить запуск или штатно заменить предыдущий процесс.
- Фоновая проверка GitHub Releases с установкой, пропуском версии и переносом решения на следующий запуск.
- Проверка SHA-256 обновлений, резервные копии и откат при ошибке замены или запуска.

### Совместимость

- Поддерживаются Windows x64 и Linux x64; Linux-сборкам нужна glibc 2.35 или новее.
- Конфигурация JSON версии 1 сохраняет параметры туннелей и доверенные SSH-ключи.
- Готовые сборки запускаются без Rust и Python.

### Исправлено

- Команда `background` на Windows завершает CLI и закрывает его перенаправленные каналы, сохраняя работу фонового процесса.
- Linux-архив сохраняет права исполнения бинарников независимо от ОС упаковки.
- Проверка PNG и ICO сверяет пиксели и структуру файлов независимо от версии PNG-сжатия.
- Проверка иконок сохраняет одинаковые окончания строк при клонировании на Windows и Linux.

### Для участников

- Интеграционные SSH-тесты запускаются независимо от приложения и требуют только тестовых Python-зависимостей.
- Код распространяется по GNU GPL версии 3; лицензии зависимостей и шрифтов сохраняются отдельно.

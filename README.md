# КРОТ

Оконный менеджер SSH-туннелей для Windows и Linux. Терминальный стиль, анимированные ASCII-кроты и работа в фоне через системный трей.

## Возможности

- Локальные и удалённые перенаправления портов, SOCKS5-прокси: режимы L, R и D.
- Цепочки jump-хостов с отдельными параметрами входа на каждом узле.
- SSH-agent, пароль и закрытый ключ, в том числе зашифрованный.
- Выбор приватного ключа через штатный диалог файлов или ввод пути вручную.
- Проверка отпечатков SSH-узлов и отдельное подтверждение при смене ключа.
- Восстановление соединений, журнал и независимое управление туннелями.
- Работа в фоне, системный трей и автозапуск после входа в систему.
- Проверка обновлений и установка с проверкой SHA-256 и резервными копиями.

Приложение написано на Rust. Для запуска готовых сборок Rust, Python и отдельный SSH-клиент не нужны. Для входа через SSH-agent требуется работающий агент с добавленным ключом.

## Установка

Откройте [последний релиз](https://github.com/Dudod1n/KPOT/releases/latest), выберите архив своей платформы и распакуйте его в каталог с правом записи.

| Платформа | Архив | Запуск |
| --- | --- | --- |
| Windows x64 | `krot-<версия>-windows-x64.zip` | `krot.exe` |
| Linux x64 | `krot-<версия>-linux-x64.tar.gz` | `./krot` |

Держите `krot` и `krot-cli` рядом: оба файла нужны для встроенного обновления. На Windows у них расширение `.exe`. Контрольные суммы опубликованы в `SHA256SUMS` рядом с архивами.

Для Linux нужны glibc 2.35 или новее, графическая сессия X11/Wayland, OpenGL/EGL и XKB. В минимальной системе может понадобиться пакет `libxkbcommon-x11-0`. Трей использует StatusNotifierItem; в GNOME обычно требуется расширение AppIndicator.

Windows-сборки пока не имеют цифровой подписи издателя. При срабатывании антивируса сверяйте источник и контрольную сумму файла; укажите название обнаружения при [сообщении об ошибке](https://github.com/Dudod1n/KPOT/issues/new/choose).

## Первый туннель

1. Нажмите **N** или кнопку создания туннеля.
2. Укажите SSH-сервер, пользователя и способ входа.
3. Выберите режим и порты, сохраните туннель.
4. Нажмите **Space** для запуска. Проверьте отпечаток узла; при необходимости введите пароль или парольную фразу ключа.

| Режим | Назначение |
| --- | --- |
| **L** | Локальный порт → сервис, доступный SSH-серверу. |
| **R** | Порт на SSH-сервере → сервис, доступный вашему компьютеру. |
| **D** | Локальный SOCKS5-прокси → сеть SSH-сервера. |

Адрес прослушивания по умолчанию — `127.0.0.1`. Для режима R доступность порта с других устройств зависит также от настроек SSH-сервера.

## Фоновая работа

Крестик закрывает окно и оставляет туннели работать. Перед первым закрытием появляется уведомление с флажком «Больше не показывать». Открыть окно снова можно через значок в трее.

Для полной остановки выберите **«Остановить КРОТ»** в меню трея или меню **Q**. Включённые туннели восстановятся при следующем запуске; ручная остановка отдельного туннеля отключает его восстановление.

Если при запуске уже работает другой экземпляр, КРОТ предложит отменить запуск или штатно завершить предыдущий процесс и запустить текущую версию. При замене процесса соединения кратковременно прервутся; пароли могут потребоваться повторно.

## Командная строка

Используйте `krot-cli` на Linux или `krot-cli.exe` на Windows:

```sh
krot-cli --help
krot-cli path
krot-cli list
krot-cli check
krot-cli background
krot-cli status
krot-cli stop
krot-cli autostart enable
```

`--config <файл>` выбирает отдельную конфигурацию. Например:

```sh
krot-cli --config ./tunnels.json check
```

## Обновления и данные

Номер версии в правом верхнем углу открывает «О программе»: сведения о сборке,
ссылку на репозиторий и анимированного крота с меняющимися при открытии репликами.

При запуске окна КРОТ проверяет последний стабильный релиз на GitHub. Можно установить обновление, пропустить конкретную версию или отложить решение до следующего запуска. Скачивание начинается после согласия.

Конфигурация хранится в `%APPDATA%\krot\config.json` на Windows и `$XDG_CONFIG_HOME/krot/config.json` или `~/.config/krot/config.json` на Linux. Пароли не записываются в конфигурацию или журнал. Параметры подключения задаются в КРОТ; системные `~/.ssh/config` и `known_hosts` не изменяются.

[Подробнее о конфигурации, ключах и обновлениях →](docs/USAGE.md)

## Сборка и участие

Нужен Rust 1.90 или новее:

```sh
git clone https://github.com/Dudod1n/KPOT.git
cd KPOT
cargo build --release --locked
```

Оконное приложение и CLI появятся в `target/release`. Инструкции по тестам и устройству кода находятся в [CONTRIBUTING.md](CONTRIBUTING.md).

Ошибки и предложения принимаются в [Issues](https://github.com/Dudod1n/KPOT/issues). Об уязвимостях сообщайте по [правилам безопасности](SECURITY.md).
